Вариант 15. Библиотека

О чем этот проект?
Это консольное приложение, которое имитирует работу электронной библиотеки. 
В программе можно искать книги, бронировать их, забирать и возвращать. А еще читатели могут подписаться на уведомления, чтобы узнавать о поступлении новых книг.

Внутри программы есть три независимые части (подсистемы):
1. Каталог — хранит список всех книг.
2. клад — следит за тем, сколько книг есть в наличии.
3. Учет читателей — хранит информацию о людях, которые записались в библиотеку.

Какие паттерны я использовал и зачем

1. Фасад (Facade) — для удобного управления
В чем была проблема:** Пользователю (или коду из `Main`) было бы очень сложно работать с библиотекой. Чтобы просто забронировать книгу, пришлось бы по очереди дергать склад, каталог и учетку, передавая данные туда-сюда. Если что-то поменять в складе, сломается весь `Main`.

Что я сделал: Я создал класс `LibraryFacade`. Теперь это единственное, с чем общается пользователь. Он просто говорит: «Забронируй книгу для Анны». А фасад сам внутри проверяет, есть ли такой читатель, есть ли книга в каталоге, и есть ли она на складе.

2. Наблюдатель (Observer) — для рассылки уведомлений
В чем была проблема:** Если бы читатели хотели узнать о новых книгах, им пришлось бы постоянно спрашивать у каталога: «Ну что, привезли что-нибудь новое?» (работал бы бесконечный цикл). Это неудобно и нагружает систему.

то я сделал:** Читатели теперь «подписываются» на каталог. Как только в каталог добавляют новую книгу, он сам рассылает всем подписчикам уведомление. При этом каталог даже не знает, кто именно на него подписан (обычный читатель или, например, бот). Если читатель отписывается, уведомления ему больше не приходят.

Структура проекта
Вся логика разбита по папкам:
 `Models` — сами сущности (Книга, Читатель, Выдача).
 `Patterns/Observer` — интерфейсы для работы паттерна Наблюдатель.
 `Patterns/Subsystems` — три подсистемы (Каталог, Склад, Учет).
 `LibraryFacade.cs` — главный класс-посредник (Фасад).
 `Program.cs` — сценарии для демонстрации (запуск и вывод в консоль).
